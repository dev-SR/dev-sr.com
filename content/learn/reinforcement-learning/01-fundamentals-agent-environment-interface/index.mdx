## The Reinforcement Learning Problem

To understand the RL problem, we first need to understand how different it is from supervised learning and unsupervised learning.

### Difference between Supervised, Unsupervised, and Reinforcement Learning

| Type                            | What does the model learn from?                         | Main goal                                         | Example                                                              |
| ------------------------------- | ------------------------------------------------------- | ------------------------------------------------- | -------------------------------------------------------------------- |
| **Supervised Learning**         | **Labeled data** (input + correct answer)               | Learn to predict the correct output for new data  | Classifying an MRI as **benign or malignant**                        |
| **Unsupervised Learning**       | **Unlabeled data**                                      | Find hidden patterns, structures, or groups       | Grouping **Iris flowers** based on similarities                      |
| **Reinforcement Learning (RL)** | **Interaction with an environment + rewards/penalties** | Learn which actions maximize **long-term reward** | An agent learning to play a game by receiving rewards for good moves |

### The key difference

Think of them as three different ways of learning:

* **Supervised:** *“Here is the question and the correct answer. Learn to answer similar questions.”*
* **Unsupervised:** *“Here is the data. Find interesting patterns or groups yourself.”*
* **Reinforcement:** *“Here is an environment. Try things, see what happens, and learn which actions lead to better rewards.”*

### Why RL is different

In supervised learning, we can explicitly tell the model what the **correct action/output** is.

In RL, we usually **don't provide the correct action**. Instead, the agent takes an action and receives a **reward signal** that tells it how good or bad the outcome was.

For example, in a game:

**State → Action → Reward → New State**

The agent might initially make random moves:

> Move right → −1 reward
> Move left → 0 reward
> Move up → +10 reward

Over many interactions, it learns a **policy**: a strategy for choosing actions that maximize the total reward over time.

So, the simplest distinction is:

> **Supervised learning learns from correct answers.**
> **Unsupervised learning finds patterns without answers.**
> **Reinforcement learning learns through trial and error using rewards.**
