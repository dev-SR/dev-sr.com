## Resource references

Aspire resources are added in AppHost and injected into consuming projects via `WithReference`.

```csharp title="AppHost/Program.cs"
var builder = DistributedApplication.CreateBuilder(args);

var postgres = builder.AddPostgres("postgres")
    .AddDatabase("catalog");

var api = builder.AddProject<Projects.CatalogApi>("catalog-api")
    .WithReference(postgres);

builder.AddProject<Projects.Storefront>("storefront")
    .WithReference(api);

builder.Build().Run();
```

      var postgres = builder.AddPostgres("postgres").AddDatabase("app");
      var cache = builder.AddRedis("cache");

      var api = builder.AddProject<Projects.ApiService>("api")
          .WithReference(postgres)
          .WithReference(cache);

      builder.AddProject<Projects.Web>("web")
          .WithReference(api);

      builder.Build().Run();

## Connection string injection

Consuming projects receive configuration automatically:

```csharp title="ApiService/Program.cs"
builder.AddServiceDefaults();
builder.AddNpgsqlDbContext<CatalogContext>("catalog");
```

Long YAML configs also collapse cleanly:

```yaml title="aspire.yaml"
resources:
  postgres:
    type: postgres
    databases:
      - catalog
  redis:
    type: redis
  catalog-api:
    type: project
    path: ../CatalogApi
    references:
      - postgres
      - redis
  storefront:
    type: project
    path: ../Storefront
    references:
      - catalog-api
```
