## What you will learn

This course walks through Aspire fundamentals: the AppHost model, resource wiring, local development, and how services communicate in a distributed .NET app.

## Course outline

- **Overview** — mental model and project layout
- **AppHost** — orchestrating APIs, databases, and caches
- **Frontend patterns** — previewing UI components alongside backend samples
- **Monitoring** — telemetry, OTLP export, and the Aspire dashboard
- **Code showcase** — large samples and multi-file tabs for docs authoring

Use the sidebar to navigate chapters. Code blocks support expand/collapse for long files, Mermaid diagrams, and architecture flow charts.
