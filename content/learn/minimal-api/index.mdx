## Course overview

Minimal APIs reduce ceremony for small services and microservices. This track covers routing, DI, validation, and testing.

## Chapters

| Chapter | Topics |
| --- | --- |
| **Routing** | Endpoints, binding, route groups, filters |
| **Validation** | FluentValidation, ProblemDetails |
| **OpenAPI** | Swashbuckle, tags, security schemes |

## First endpoint

```csharp title="Program.cs"
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

app.MapGet("/health", () => Results.Ok(new { status = "ok" }));

app.Run();
```
