## What this chapter covers

Minimal APIs map HTTP verbs directly to delegates. Nested pages walk through:

- **Endpoints** — `MapGet`, binding, typed results
- **Route groups** — prefixes, OpenAPI tags, authorization filters

Each page includes long samples that collapse in the sidebar-friendly docs layout.
