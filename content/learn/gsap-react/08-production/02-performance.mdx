## Cleanup checklist

- **`useGSAP`** reverts context on unmount
- **`ScrollTrigger.getAll().forEach(t => t.kill())`** on SPA route change if needed
- **`split.revert()`** for SplitText
- **`Draggable.get(...).kill()`** when removing drag targets
- Pause or kill off-screen animations

## will-change

Hint the browser only on elements that **will** animate:

```css
.will-animate {
  will-change: transform;
}
```

Do not set on every element preemptively.
