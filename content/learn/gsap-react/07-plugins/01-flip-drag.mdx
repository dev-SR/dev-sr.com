## Layout and pointer plugins

These plugins cover three different jobs: **Flip** animates between two layouts, **Draggable** makes elements pointer-movable, and **Observer** turns gestures into callbacks without owning the DOM transform yourself.

## Flip grid ↔ list

**Flip** (First, Last, Invert, Play) records positions with `Flip.getState`, you change the DOM (grid ↔ list), then `Flip.from` animates from the recorded state to the new layout. Capture state **before** the React/DOM update; run `Flip.from` after paint (`requestAnimationFrame`).

Toggle layout: items travel to their new slots instead of popping. `absolute: true` helps during the flight when flow would otherwise jump.

<ComponentPreview>
  <GsapFlipGrid />

  <DocsFileTabs title="Flip layout">

```tsx title="flip-layout.tsx"
import { Flip } from 'gsap/Flip';

const state = Flip.getState('.item');
setGrid(!grid); // DOM change
requestAnimationFrame(() => {
  Flip.from(state, { duration: 0.5, ease: 'power2.inOut', absolute: true });
});
```

## Draggable + inertia

**Draggable** attaches pointer drag to `x`/`y` (or rotation, scroll). Pair with **InertiaPlugin** so release flings with momentum and settles against `bounds`. `edgeResistance` softens the walls.

Drag the card and release: it coasts, then stops inside the dashed frame.

<ComponentPreview>
  <GsapDraggableCard />

  <DocsFileTabs title="Draggable">

```tsx title="draggable.tsx"
import { Draggable } from 'gsap/Draggable';
import { InertiaPlugin } from 'gsap/InertiaPlugin';
gsap.registerPlugin(Draggable, InertiaPlugin);

Draggable.create('.card', {
  type: 'x,y',
  bounds: container,
  inertia: true,
  edgeResistance: 0.65,
});
```

```html title="draggable-markup.html"

  <div class="gsap-drag-card absolute cursor-grab rounded-lg border bg-card p-3">
    Drag me
  </div>
</div>
```

## Observer swipe

**Observer** listens for wheel, touch, and pointer gestures and fires `onLeft` / `onRight` (and more) without implementing drag math. Use it for carousels and swipe navigation where you animate the track yourself.

Swipe or drag sideways on the stage: slides advance with a tolerance so tiny moves do not count.

<ComponentPreview>
  <GsapObserverSwipe />

  <DocsFileTabs title="Observer swipe">

```tsx title="observer-swipe.tsx"
Observer.create({
  target: area,
  type: 'touch,pointer',
  onLeft: () => nextSlide(),
  onRight: () => prevSlide(),
  tolerance: 20,
});
```

```html title="observer-swipe-markup.html"
    <div class="min-w-full">Pricing</div>
  </div>
</div>
```
