## Transform aliases

GSAP's `x`, `y`, `scale`, and `rotation` map to compositor-friendly transforms — not `left`, `top`, or `width`.

| GSAP | Prefer over |
| --- | --- |
| `x`, `y` | `left`, `top`, `margin` |
| `xPercent` | percentage `translate` for drawers |
| `scale` | animating `width`/`height` for simple zoom |
| `transformOrigin` | popovers scaling from trigger |

## Origin-aware popover

Popovers scale from the trigger, not center:

<ComponentPreview>
  <GsapOriginPopover />

  <DocsFileTabs title="Popover origin">

```tsx title="popover-origin.tsx"
gsap.fromTo('.gsap-popover', { scale: 0.95, autoAlpha: 0 }, {
  scale: 1,
  autoAlpha: 1,
  duration: 0.2,
  ease: 'power2.out',
  transformOrigin: 'top left',
});
```

```html title="popover-origin-markup.html"
<div class="relative">
  <button>Filter</button>
  <!-- transformOrigin: 'top left' on .gsap-popover -->
  <div class="gsap-popover absolute left-0 top-full mt-2 w-44 rounded-lg border bg-card p-3">
    <p>Status</p>
    <p>Active · Draft · Archived</p>
  </div>
</div>
```

  </DocsFileTabs>
</ComponentPreview>

## Good vs bad

<ComponentPreview>
  <GsapTransformVsLayout />

  <DocsFileTabs title="Transform vs layout">

```tsx title="transform-vs-layout.tsx"
gsap.to('.gsap-good', { x: 80, duration: 1, repeat: -1, yoyo: true }); // GPU
gsap.to('.gsap-bad', { left: 80, duration: 1, repeat: -1, yoyo: true }); // layout
```

```html title="transform-vs-layout-markup.html"
<div>
  <p>Good: transform x (GPU)</p>
  <div class="relative h-10">
    <div class="gsap-good absolute left-0 top-1 size-8 rounded"></div>
  </div>
  <p>Avoid: left (layout)</p>
  <div class="relative h-10">
    <div class="gsap-bad absolute left-0 top-1 size-8 rounded"></div>
  </div>
</div>
```

  </DocsFileTabs>
</ComponentPreview>

Use `clearProps` when a class should take over after the tween completes.
