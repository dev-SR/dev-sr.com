## What you will learn

This course teaches GSAP in React from first tween to scroll-driven product motion. Every lesson pairs prose with **live previews** — click **Replay** on one-shot entrances, interact with click/drag demos, and scroll inside isolated stages so demos never fight this site's Lenis scroll.

<Callout variant="tip" title="When not to animate">
  High-frequency UI (command palettes, keyboard shortcuts) should not animate. GSAP shines on modals, toasts, scroll storytelling, layout transitions, and SVG — not every `:active` press.
</Callout>

Register plugins once at module scope (never inside a component):

```tsx title="lib/gsap.ts"
import gsap from 'gsap';
import { useGSAP } from '@gsap/react';
import { ScrollTrigger } from 'gsap/ScrollTrigger';

gsap.registerPlugin(useGSAP, ScrollTrigger);
```
