You can create many `experiments` and nested/child `runs`. Where:

<ItemList>
    <ListItem icon="Boxes">
        <ListTitle>Experiments</ListTitle>
        <LineItem>
            An **experiment** is a container for related machine learning runs. It provides a way to group and compare training attempts for a particular objective.
        </LineItem>
        <LineItem>
            For example:
            - `02_regression_experiment` — experiments with models that predict continuous values.
            - `02_classification_experiment` — experiments with models that predict class labels.
        </LineItem>
        <LineItem>
            Each experiment has a unique experiment ID. Experiments can also have descriptive names to make them easier to identify.
        </LineItem>
    </ListItem>
    <ListItem icon="Package">
        <ListTitle>Runs</ListTitle>
        <LineItem>
            A **run** represents one execution of a machine learning workflow. A run can record:
        </LineItem>
        <LineItem>
            - `Parameters`: Configuration values such as n_estimators and max_depth.
            - `Metrics`: Evaluation results such as RMSE and accuracy.
            - `Tags`: Metadata describing the run, such as its stage, team, or purpose.
            - `Artifacts`: Files produced during training, such as model files, plots, and evaluation reports.
        </LineItem>
        <LineItem>
            For example, training a random forest with 100 trees and a maximum depth of 4 can be recorded as one run. Changing the maximum depth to 6 and training again produces another run.
        </LineItem>
    </ListItem>
    <ListItem icon="Package">
        <ListTitle>Nested Runs</ListTitle>
        <LineItem>
            A **nested run** is a run created inside another run, known as the parent run. It helps organize related training runs under a common task, such as *hyperparameter tuning*, *model comparison*, or an *experiment with multiple configurations*.
        </LineItem>
        <LineItem>
            For example, a hyperparameter search may test different values of n_estimators and max_depth. The parent run represents the overall search, while each child run records the results of one parameter combination.
            
            ```text
            Experiment: 02_regression_experiment
            ├── Run: rf_baseline
            └── Parent Run: rf_hyperparameter_sweep
                ├── Child Run: rf_50_3
                ├── Child Run: rf_50_5
                ├── Child Run: rf_100_3
                └── Child Run: rf_100_5
            ```
        </LineItem>
    </ListItem>
</ItemList>


## 🤖 Creating Multiple Experiments & Runs

```python showLineNumbers {1}
import numpy as np
import mlflow
from sklearn.datasets import load_diabetes, load_breast_cancer
from sklearn.ensemble import RandomForestRegressor, RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, accuracy_score

# Initialize MLflow tracking
mlflow.set_tracking_uri("sqlite:///mlflow.db")

# --------------------------------------------------
# 1. Experiment 1: Regression (Baseline & Sweep)
# --------------------------------------------------
mlflow.set_experiment("02_regression_experiment")

X_reg, y_reg = load_diabetes(return_X_y=True, as_frame=True)
X_train_r, X_test_r, y_train_r, y_test_r = train_test_split(
    X_reg, y_reg, test_size=0.2, random_state=42
)

# Baseline run
with mlflow.start_run(run_name="rf_regression_baseline"):
    mlflow.set_tags({"team": "ml_platform", "stage": "baseline"})
    model = RandomForestRegressor(n_estimators=100, max_depth=4, random_state=42)
    model.fit(X_train_r, y_train_r)
    rmse = float(np.sqrt(mean_squared_error(y_test_r, model.predict(X_test_r))))

    mlflow.log_params(
        {"model": "RandomForestRegressor", "n_estimators": 100, "max_depth": 4}
    )
    mlflow.log_metric("rmse", rmse)

# Nested runs: hyperparameter sweep
with mlflow.start_run(run_name="rf_regression_sweep") as parent_run:
    mlflow.set_tags({"search_type": "manual_grid", "objective": "minimize_rmse"})
    mlflow.log_param("search_space", "n_estimators x max_depth")

    for n_estimators in [50, 100]:
        for max_depth in [3, 5]:
            with mlflow.start_run(
                run_name=f"rf_reg_{n_estimators}_{max_depth}", nested=True
            ):
                model = RandomForestRegressor(
                    n_estimators=n_estimators, max_depth=max_depth, random_state=42
                )
                model.fit(X_train_r, y_train_r)
                rmse = float(
                    np.sqrt(mean_squared_error(y_test_r, model.predict(X_test_r)))
                )

                mlflow.log_params(
                    {
                        "model": "RandomForestRegressor",
                        "n_estimators": n_estimators,
                        "max_depth": max_depth,
                    }
                )
                mlflow.log_metric("rmse", rmse)


# --------------------------------------------------
# 2. Experiment 2: Classification (Baseline & Sweep)
# --------------------------------------------------
mlflow.set_experiment("02_classification_experiment")

X_clf, y_clf = load_breast_cancer(return_X_y=True, as_frame=True)
X_train_c, X_test_c, y_train_c, y_test_c = train_test_split(
    X_clf, y_clf, test_size=0.2, random_state=42, stratify=y_clf
)

# Baseline run
with mlflow.start_run(run_name="rf_classifier_baseline"):
    mlflow.set_tags({"team": "ml_platform", "stage": "baseline"})
    classifier = RandomForestClassifier(n_estimators=100, max_depth=5, random_state=42)
    classifier.fit(X_train_c, y_train_c)
    acc = float(accuracy_score(y_test_c, classifier.predict(X_test_c)))

    mlflow.log_params(
        {"model": "RandomForestClassifier", "n_estimators": 100, "max_depth": 5}
    )
    mlflow.log_metric("accuracy", acc)

# Nested runs: hyperparameter sweep for classification
with mlflow.start_run(run_name="rf_classifier_sweep") as parent_run_c:
    mlflow.set_tags({"search_type": "manual_grid", "objective": "maximize_accuracy"})
    mlflow.log_param("search_space", "n_estimators x max_depth")

    for n_estimators in [50, 100]:
        for max_depth in [3, 7]:
            with mlflow.start_run(
                run_name=f"rf_clf_{n_estimators}_{max_depth}", nested=True
            ):
                classifier = RandomForestClassifier(
                    n_estimators=n_estimators, max_depth=max_depth, random_state=42
                )
                classifier.fit(X_train_c, y_train_c)
                acc = float(accuracy_score(y_test_c, classifier.predict(X_test_c)))

                mlflow.log_params(
                    {
                        "model": "RandomForestClassifier",
                        "n_estimators": n_estimators,
                        "max_depth": max_depth,
                    }
                )
                mlflow.log_metric("accuracy", acc)

```


### Autologging

Add one line to automatically log parameters, metrics, and models.

```python
import mlflow
from sklearn.ensemble import RandomForestRegressor
from sklearn.datasets import load_diabetes
from sklearn.model_selection import train_test_split

mlflow.autolog()

db = load_diabetes()
X_train, X_test, y_train, y_test = train_test_split(db.data, db.target)

rf = RandomForestRegressor(n_estimators=100, max_depth=6)
rf.fit(X_train, y_train)  # MLflow logs automatically
```

**Supported libraries:** Scikit-learn, XGBoost, LightGBM, PyTorch, Keras/TensorFlow, Spark, and more.

**Customize autologging:**

```python
mlflow.autolog(
    log_model_signatures=False,
    extra_tags={"team": "data-science"}
)
```

📖 **Official docs:** [Automatic Logging](https://mlflow.org/docs/latest/ml/tracking/autolog/)

## 🖥️ 7 – Tracking Server

Start a central server for team collaboration.

```bash

  --backend-store-uri sqlite:///mlflow.db \

  --default-artifact-root s3://my-bucket/mlflow-artifacts \
  --host 0.0.0.0 \
  --port 5000
```

## 📦 8 & 9 – Models & Custom Models

### Logging a Built-in Model

```python
import mlflow.sklearn
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_iris
from mlflow.models import infer_signature

X, y = load_iris(return_X_y=True, as_frame=True)
model = RandomForestClassifier().fit(X, y)

signature = infer_signature(X, model.predict(X))

with mlflow.start_run():
    mlflow.sklearn.log_model(
        sk_model=model,
        artifact_path="model",
        signature=signature,
        input_example=X.iloc[[0]]
    )
```

### Custom PyFunc Model

```python
import mlflow
import pandas as pd

class CustomModel(mlflow.pyfunc.PythonModel):
    def predict(self, context, model_input):
        # Custom logic: return square of input
        return model_input ** 2

with mlflow.start_run():
    model_info = mlflow.pyfunc.log_model(
        artifact_path="model",
        python_model=CustomModel()
    )

loaded_model = mlflow.pyfunc.load_model(model_info.model_uri)
print(loaded_model.predict(pd.DataFrame([2, 3, 4])))  # [4, 9, 16]
```

**Custom model with artifacts:**

```python
class ModelWithArtifacts(mlflow.pyfunc.PythonModel):
    def load_context(self, context):
        import pickle
        with open(context.artifacts["model_file"], "rb") as f:
            self.model = pickle.load(f)

    def predict(self, context, model_input):
        return self.model.predict(model_input)

mlflow.pyfunc.log_model(
    artifact_path="model",
    python_model=ModelWithArtifacts(),
    artifacts={"model_file": "path/to/model.pkl"}
)
```

📖 **Official docs:** [Custom PyFunc Models](https://mlflow.org/docs/latest/ml/model/custom-pyfunc/)

## 📊 10 – Model Evaluation

Automated metrics and visualizations for classification/regression.

### Classification Example

```python
import mlflow
import xgboost as xgb
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from mlflow.models import infer_signature

X, y = load_breast_cancer(return_X_y=True, as_frame=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)

model = xgb.XGBClassifier().fit(X_train, y_train)

eval_data = X_test.copy()
eval_data["label"] = y_test

with mlflow.start_run():
    signature = infer_signature(X_test, model.predict(X_test))
    model_info = mlflow.sklearn.log_model(model, "model", signature=signature)

    result = mlflow.models.evaluate(
        model_info.model_uri,
        eval_data,
        targets="label",
        model_type="classifier"
    )

    print(f"Accuracy: {result.metrics['accuracy_score']:.3f}")
    print(f"F1 Score: {result.metrics['f1_score']:.3f}")
    print(f"ROC AUC: {result.metrics['roc_auc']:.3f}")
```

### Regression Example

```python
from sklearn.datasets import fetch_california_housing
from sklearn.linear_model import LinearRegression

X, y = fetch_california_housing(return_X_y=True, as_frame=True)
model = LinearRegression().fit(X, y)

eval_data = X.copy()
eval_data["target"] = y

result = mlflow.models.evaluate(
    model_info.model_uri,
    eval_data,
    targets="target",
    model_type="regressor"
)
```

**Auto‑generated:** accuracy, precision, recall, F1, ROC‑AUC (classification); MSE, RMSE, R², MAE (regression); confusion matrix, ROC curve, SHAP feature importance.

📖 **Official docs:** [Model Evaluation](https://mlflow.org/docs/latest/ml/evaluation/)

## 🗂️ 11 – Model Registry

Central catalog for versioning and stage management.

### Register a Model

```python
import mlflow
from mlflow.tracking import MlflowClient

with mlflow.start_run() as run:
    # ... train and log model ...
    model_uri = f"runs:/{run.info.run_id}/model"
    model_version = mlflow.register_model(model_uri, "iris-classifier")
    print(f"Name: {model_version.name}, Version: {model_version.version}")
```

### Transition Stages

```python
client = MlflowClient()

# Promote to Staging
client.transition_model_version_stage(
    name="iris-classifier",
    version=1,
    stage="Staging"
)

# Promote to Production (archive old production versions)
client.transition_model_version_stage(
    name="iris-classifier",
    version=1,
    stage="Production",
    archive_existing_versions=True
)
```

### Load Model by Stage

```python
import mlflow.pyfunc
model = mlflow.pyfunc.load_model("models:/iris-classifier/Production")
predictions = model.predict(X_test)
```

📖 **Official docs:** [Model Registry](https://mlflow.org/docs/latest/ml/model-registry/)

## 📁 12 – MLflow Projects

Package code for reproducible runs.

### `MLproject` File

```yaml
name: my-ml-project
python_env: python_env.yaml

entry_points:
  main:
    parameters:
      alpha: {type: float, default: 0.5}
      data_file: path
    command: "python train.py --alpha {alpha} --data {data_file}"

  validate:
    parameters:
      model_path: path
      test_data: path
    command: "python validate.py {model_path} {test_data}"
```

### `python_env.yaml`

```yaml
python: "3.10"
dependencies:
  - mlflow
  - scikit-learn
  - pandas
```

### Run the Project

```bash
# From local directory
mlflow run . -P alpha=0.3 -P data_file=data.csv

# From GitHub
mlflow run https://github.com/user/repo.git -P alpha=0.5

# Specific entry point
mlflow run . -e validate -P model_path=model.pkl -P test_data=test.csv
```

### Programmatic Execution

```python

result = mlflow.run(
    "https://github.com/user/repo.git",
    parameters={"alpha": 0.5},
    experiment_name="elasticnet-experiment"
)
```

## 🧰 13 – MLflow Client

Low‑level CRUD API for full control.

### Initialization & Run Management

```python
from mlflow import MlflowClient

client = MlflowClient(tracking_uri="http://localhost:5000")

# Create a run under experiment id "0" (default)
run = client.create_run(experiment_id="0")
run_id = run.info.run_id

# Log data to the run
client.log_param(run_id, "learning_rate", 0.01)
client.log_metric(run_id, "accuracy", 0.95)

# End the run
client.set_terminated(run_id)
```

### Search Experiments & Runs

```python
experiments = client.search_experiments()
for exp in experiments:
    print(exp.name)

runs = client.search_runs(
    experiment_ids=["0"],
    filter_string="metrics.accuracy > 0.9",
    order_by=["metrics.accuracy DESC"],
    max_results=5
)
for r in runs:
    print(r.info.run_id, r.data.metrics)
```

### Model Registry Operations

```python
# Create a registered model
client.create_registered_model("my-model")

# Create a model version
client.create_model_version(
    name="my-model",
    source="runs:/<run_id>/model",
    run_id="<run_id>"
)

# Transition stage
client.transition_model_version_stage(
    name="my-model",
    version=1,
    stage="Production"
)
```

📖 **Official docs:** [MlflowClient API](https://mlflow.org/docs/latest/python_api/mlflow.client.html)

## ⌨️ 14 – MLflow CLI Commands

Essential commands for terminal workflows.

```bash
# Start tracking server
mlflow server --backend-store-uri sqlite:///mlflow.db --port 5000

# Run a project
mlflow run https://github.com/mlflow/mlflow-example.git -P alpha=0.5

# Create experiment
mlflow experiments create --experiment-name "my-experiment"

# List experiments
mlflow experiments search

# List runs in an experiment
mlflow runs list --experiment-id 1

# Describe a run
mlflow runs describe --run-id <run_id>

# Download artifacts
mlflow artifacts download --run-id <run_id> --artifact-path model --dst-path ./downloads

# Serve a model locally
mlflow models serve -m runs:/<run_id>/model -p 1234

# Build a Docker image for a model
mlflow models build-docker -m runs:/<run_id>/model -n my-model-image

# Register a model
mlflow models register -m runs:/<run_id>/model -n my-model
```

📖 **Official docs:** [Command‑Line Interface](https://mlflow.org/docs/latest/cli.html)

## ☁️ 15 – AWS Integration: End‑to‑End Project

Full workflow: train locally, log to S3, register, and deploy to SageMaker.

### 1. Install AWS MLflow Plugin

```bash
pip install sagemaker-mlflow
```

### 2. Connect to SageMaker MLflow Tracking Server

```python
import mlflow

# Your SageMaker MLflow tracking server ARN
tracking_server_arn = "arn:aws:sagemaker:region:account:mlflow-tracking-server/your-server"
mlflow.set_tracking_uri(tracking_server_arn)
mlflow.set_experiment("aws-end-to-end")
```

### 3. Train & Log Model

```python
import mlflow.sklearn
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from mlflow.models import infer_signature

X, y = load_iris(return_X_y=True, as_frame=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

with mlflow.start_run(run_name="sagemaker-rf"):
    model = RandomForestClassifier(n_estimators=100)
    model.fit(X_train, y_train)

    signature = infer_signature(X_train, model.predict(X_train))
    mlflow.sklearn.log_model(
        sk_model=model,
        artifact_path="model",
        signature=signature,
        registered_model_name="iris-sagemaker"
    )
```

### 4. Deploy to SageMaker Endpoint

```python
import sagemaker_mlflow

# Log inference specification for SageMaker
sagemaker_mlflow.log_inference_specification(
    model_info.model_id,
    inference_specification={
        "supported_content_types": ["text/csv"],
        "supported_response_types": ["text/csv"]
    }
)

# Register and deploy
model_version = mlflow.register_model(
    f"models:/iris-sagemaker/1",
    "iris-sagemaker-prod"
)
```

### 5. Batch Inference with SageMaker

```python
from sagemaker.predictor import Predictor

predictor = Predictor(
    endpoint_name="iris-sagemaker-endpoint",
    sagemaker_session=sagemaker.Session()
)

# Predict
result = predictor.predict(X_test.iloc[:5].to_csv(index=False))
print(result)
```

**AWS services used:** SageMaker MLflow Tracking Server, S3 (artifact store), SageMaker Endpoints (serving), IAM (permissions).

📖 **Official docs:** [Integrate MLflow with your environment](https://docs.aws.amazon.com/sagemaker/latest/dg/mlflow-track-experiments.html)
