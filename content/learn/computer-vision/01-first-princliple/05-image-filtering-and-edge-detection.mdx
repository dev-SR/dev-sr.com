## Introduction

Image filtering is a fundamental technique in computer vision and digital image processing. It allows us to modify images to reduce noise, smooth variations in intensity, enhance important features, and detect object boundaries. These operations play an essential role in many applications, including image enhancement, object recognition, medical imaging, and autonomous systems.

In this chapter, we will explore the fundamental concepts of image filtering using Python, NumPy, Matplotlib, and OpenCV. We will begin by examining how digital images are represented as numerical arrays and how convolution kernels operate on neighboring pixels to produce filtered images. We will then implement a simple averaging filter from scratch and compare its results with OpenCV's optimized filtering functions.

Next, we will investigate directional edge detection using vertical and horizontal kernels, followed by bilateral filtering, which reduces noise while helping preserve important image edges. Finally, we will introduce the Canny edge detector, a widely used technique for identifying clear and well-defined edges.

Throughout the chapter, we will visualize and compare the results of different filtering techniques to develop an intuitive understanding of how each method works, when it is useful, and how it can be applied to practical computer vision problems.
