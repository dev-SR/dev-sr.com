## Protected collections

`IReadOnlyCollection<Rental>` stops callers from `Add`/`Clear` on the live list. Mutations stay on `Customer` (`AddRental`).

## Value objects

| Primitive smell | Value object |
| --- | --- |
| `decimal Fee` | `Money` (amount + currency rules) |
| `StartDate` + `EndDate` | `RentalPeriod` (range invariants) |

Value objects are **immutable**, compared by value, and validate themselves. Entities stay focused on identity and lifecycle.

## Exceptions vs domain errors

Throwing for every bad input forces HTTP layers into `catch` chains. Prefer `Result<T>` for expected business failures; reserve exceptions for truly unexpected bugs.
