title: 'Move logic'
description: 'Pull lookups, creation, and fee calculation out of the service.'
---

## Target shape

The service should **orchestrate**, not decide:

```csharp
return Rental.Create(customer, equipment, startDate, endDate);
```

## Moves

| From service | To domain |
| --- | --- |
| Find customer / equipment | `Customer.FindById`, `Equipment.FindById` |
| Build rental + validate dates | `Rental.Create(...)` |
| Fee = days × rate | private logic inside `Rental` |
| Flip availability | `equipment.Reserve()` / `Release()` |

After this step the service still throws on missing entities; entities own the rental workflow.

<Callout variant="tip" title="Ubiquitous language">
  Method names should match how the business talks: `Reserve`, not `SetAvailableFalse`.
</Callout>
