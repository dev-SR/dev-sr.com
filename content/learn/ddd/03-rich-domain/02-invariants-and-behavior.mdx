## Construction invariants

Private constructors + factories keep bad objects from existing:

```csharp
private Customer(string id, string name)
{
    if (string.IsNullOrWhiteSpace(name))
        throw new ArgumentException("Name cannot be null or empty.", nameof(name));
    Id = id;
    Name = name;
}
```

## Workflow invariants

`Rental.Create` rejects invalid ranges, past starts, and unavailable equipment — before mutating anything.

## Behavior over setters

| Instead of | Prefer |
| --- | --- |
| `Name = value` | `UpdateContactInformation(name)` |
| `Available = false` | `Reserve()` / `Release()` |
| `customer.Rentals.Add(...)` | `internal AddRental` + `IReadOnlyCollection` |

Expose **what the domain allows**, not every field the database happens to store.
